# Personal Nest API

This folder is for **one** NestJS app you grow yourself — not a per-video course project.

কোর্সে যা শিখবে (`course/`-এ), এখানে একটা অ্যাপে জোড়া লাগাবে।

Scaffold when ready (from the repo root, after removing this placeholder or using another directory name):

```bash
npx @nestjs/cli new app --directory app
```
